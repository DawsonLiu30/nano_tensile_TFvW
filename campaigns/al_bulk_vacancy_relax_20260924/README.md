# 鋁體相空位：初始結構與 QE 輸入包（2026-09-24）

本資料包保存一組共同晶胞中的完整晶體、單空位及六種雙空位**理想初始結構**，供 DFTpy 與 Quantum ESPRESSO（QE）後續固定晶胞、原子鬆弛計算使用。包內沒有計算結果，不表示電子或原子鬆弛已收斂。實際作業與結果狀態由另外的計算紀錄管理。

## 晶胞與格點

- 晶體：單晶 FCC Al，3 × 3 × 3 傳統立方晶胞；三方向週期邊界，無真空。
- 共同晶格尺度：`a_ref = 3.9545804060131293 Å`。
- 晶胞邊長：`L = 11.863741218039388 Å`，即約 12 Å。**12 Å 是晶胞邊長，不是兩空位間距。**
- 此 `a_ref` 沿用歷史受控比較的共同固定值，**不是新 EOS 擬合所得的平衡晶格常數，也不宣稱為 QE 的平衡值**。
- 完整模型有 108 個晶格位點；0V、1V、2V 分別有 108、107、106 個 Al 原子。
- 第一空位固定在中心，parent site ID 為 **43**（0-based），分率座標 `(0.5, 0.5, 0.5)`，笛卡兒座標約 `(5.931870609, 5.931870609, 5.931870609) Å`。
- 所有初態來自同一組 FCC 格點；共同原點平移 `(a_ref/2, a_ref/2, a_ref/2)` 只為讓第一空位位於晶胞中心，不改变晶體物理內容。原子輸出順序對應 `geometry.json` 的 `remaining_parent_ids`；extxyz 另存 `parent_site_id` 欄位。

## 資料位置

- `geometry.json`：晶胞、全部原始格點、8 組案例、移除位點、完整原子對應、MIC 向量及最近／下一層影像資料。
- `structures/<case>/POSCAR`：可由 VESTA 或 ASE 讀取的初始結構。
- `structures/<case>/structure.extxyz`：相同初始結構，附每原子的 parent site ID。
- `qe_manifest.json`：QE 計算條件及每份輸入／結構／偽勢的 SHA-256。
- `qe/inputs/<case>/pw.in`：QE 固定晶胞 `relax` 輸入；全部从本包的理想 FCC 初態開始。
- `pseudo/Al.pz-vbc.UPF`：本輪一致的 LDA 偽勢。
- ZIP 另附 `al_bulk_vacancy_initial_structures_20260924.png` 六面板圖及同名 `.csv` 八案例表；空心叉標記代表缺少的原子。
- ZIP 另附 `SHA256SUMS.json`，記錄包內來源檔的 SHA-256。封包另以重新讀取來源檔與 ZIP 的方式逐檔核對。

QE 輸入中的 `pseudo_dir = '../../../pseudo'` 以各 `qe/inputs/<case>` 資料夾為工作目錄解析；移動檔案時需保留目錄關係。`outdir = './scratch'` 是計算時的暫存位置。這是輸入資料包，不是自動提交器；正式執行由專案 runner 建立獨立輸出位置及作業紀錄。

## 計算設定與可支持的解讀

本輪 QE 起始設定：LDA `Al.pz-vbc.UPF`，波函數／密度 cutoff 60／240 Ry，3 × 3 × 3 無位移 k 點，MV 展寬 0.02 Ry，200 bands，SCF 門檻 10⁻⁹ Ry，BFGS 原子鬆弛，晶胞固定。QE 原子力分量停止值為 0.0005 eV/Å，後處理另檢查最大原子力向量長度不超過 0.001 eV/Å；詳細數值以 `qe_manifest.json` 為準。這些是**待驗證的起始數值條件**，不是已完成 cutoff／k 點／展寬／尺寸收斂的聲明。

六個雙空位初態是不同位置配置的比較，**不是空位凝聚或原子遷移的連續軌跡**。一般結構鬆弛的最佳化步數也不代表物理時間；遷移能障需要另作路徑計算。

108-site 週期晶胞中的結果仍可能受到缺陷週期影像及濃度影響。即使後續某個作業收斂，也還需更大晶胞、數值條件與位置對應的查核；不能只因約 12 Å 或 MIC 定義正確，就宣稱孤立空位或無限尺寸極限已收斂。

準備階段已檢查 108 個唯一 FCC 格點、完整晶體每格點 12 個最近鄰、108／107／106 原子數、共用晶胞、移除／保留 site ID 對應及六種 MIC 距離。ASE 獨立讀入 POSCAR 與 extxyz，核對兩格式座標、晶胞、parent IDs 及 MIC 距離一致。這些是**幾何與檔案一致性驗證**，不取代正式物理計算。
