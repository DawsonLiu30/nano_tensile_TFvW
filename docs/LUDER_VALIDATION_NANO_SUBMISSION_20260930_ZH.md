E_f(1V)=E(1V)−107E(0V)/108；E_f(2V)=E(2V)−106E(0V)/108；E_b=2E(1V)−E(2V)−E(0V)；D12=E(1NN)−E(2NN)。

## 4. 完成後如何分析，哪些事尚未完成

每一方法內計算 E_f^wire=E_wire(N−1)−E_wire(N)+μ_bulk，μ_bulk=E_bulk/N_bulk；不使用柱子每原子能量替代 bulk 化學勢，也不跨方法相減絕對總能量。先列明採用哪一個 bulk k/grid 參考，再報其敏感性。分析包括原子位移、近鄰距離、配位、軸向晶胞應變、原始與去除均勻變形後的結構改變，並確認終態空缺是否仍留在內部。

奈米柱的程式應力用含真空的盒體積歸一化，不能直接冒稱柱體真實應力或與 bulk GPa 無條件對照。必要時用軸向力 σzz×A_box 或先定義有效截面。

這是第一批 pilot，不是已完成真空、軸向長度、k 點／grid 收斂的結論。每約14 Å 放一個 vacancy，仍是週期缺陷陣列。近表面單空缺、nano 2V、bonus B0(λ,μ) 與 bulk 1V B0 尚未提交；先依 Luder 指示完成可檢驗的單空缺能量／結構，再決定後續最小矩陣。
